# Restaurant-Consumer-Data-Analysis
SQL-based analysis of restaurant performance, consumer spending, and cuisine preferences using CTEs, views, stored procedures, and window functions.

## Overview

This project focuses on analyzing restaurant performance, consumer spending behavior, and cuisine preferences using SQL. The analysis uses advanced SQL concepts to extract meaningful insights from restaurant and consumer data.

## Objectives

- Analyze consumer spending patterns
- Identify the highest-spending consumers
- Evaluate restaurant performance
- Analyze cuisine preferences
- Extract meaningful insights using SQL

## SQL Concepts Used

- Common Table Expressions (CTEs)
- Views
- Stored Procedures
- Window Functions
- Aggregate Functions
- Joins
- Subqueries
- GROUP BY and HAVING

## Key Analysis

The project includes analysis of:

- Consumer spending and budget segmentation
- Highest-spending consumers
- Top-performing restaurants
- Restaurant performance
- Cuisine preferences
- Consumer and restaurant relationships

## Technologies Used

- SQL
- MySQL
